# Spare loading sounds

`dreaming/` — "I am dreaming or Final Fantasy menu kinda thing" (Pixabay,
freesound_community), sped up 1.5x with the pitch kept, as a 2.7 s loop plus
its 10.8 s build-up. Runner-up to the arpeggios (25 Nov 2026).

To use it instead of the current loading sound, copy both files over the ones
in `assets/sounds/`:

    cp assets/sounds/alternatives/dreaming/waiting_build.wav assets/sounds/
    cp assets/sounds/alternatives/dreaming/waiting_loop.wav  assets/sounds/

Or point the app at the folder for a quick try: `SOUNDS_DIR` must then also
hold `boot.wav` (and `ready.wav`), so copying is simpler.

Demo only: Pixabay sounds, chosen for the demo, not for the final product.
